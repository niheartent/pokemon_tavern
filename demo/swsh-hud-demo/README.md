# 剑盾 HUD 交互 Demo

这是当前讨论中的剑盾 HUD 交互样稿独立副本。它只使用静态示例数据，用于确认主菜单、队伍、盒子、背包、设置和响应式布局的视觉与交互。

## 使用范围

- 横屏和手机竖屏预览
- 白天和暗色主题切换
- 主菜单入口与底部操作提示
- 队伍选择、详情页和页面返回
- 盒子 5 列方格、空位、滚动、悬停标签、右侧资料和转移按钮
- 本地剑盾风格图标、背景、水印和宝可梦图标

## 运行

可以直接打开 `index.html`。如果浏览器限制本地资源或需要稳定测试滚动，建议在本目录启动静态服务器：

```powershell
python -m http.server 8767
```

然后访问：<http://127.0.0.1:8767/>

## 目录

```text
swsh-hud-demo/
├─ index.html       当前交互 demo
├─ assets/          demo 使用的本地图标、背景、水印和宝可梦资源
└─ README.md        本说明
```

## 边界

这是讨论用 demo，不连接弦九、不读取角色卡、不写 IndexedDB、不执行更新器，也不属于正式发布包。确认设计后，才把明确的规则迁移到 `src/swsh/` 正式 HUD。

横屏和竖屏的视觉布局在 demo 中分别维护，不能把横屏页面拉伸成竖屏成品。修改 demo 时优先使用本目录的资源，不依赖工作区外的解包路径。
