## 🐛 常见问题排查

### 问题1：CSS文件404

**症状**：页面无样式，控制台显示CSS文件加载失败

**原因**：相对路径错误或未启动HTTP服务器

**解决**：
```bash
cd D:\workspace\pokemon_tavern\demo\swsh-hud-demo
python -m http.server 8768
# 访问 http://127.0.0.1:8768/index-test-modular.html
```

### 问题2：样式加载顺序错误

**症状**：部分样式不生效，被覆盖

**原因**：CSS文件加载顺序不对

**解决**：检查 `<head>` 中的顺序：
1. tokens.css (变量定义)
2. base.css (基础)
3. layout.css (布局)
4. backdrops/*.css (背景)
5. components.css (组件)
6. modules/*.css (模块)
7. responsive.css (响应式)

### 问题3：选择器优先级问题

**症状**：某些样式被意外覆盖

**原因**：模块化后选择器优先级改变

**解决**：在开发者工具中检查"Computed"标签，查看最终生效的样式

## 🔧 调试技巧

### 快速定位问题

```javascript
// 在浏览器控制台运行
// 检查CSS变量
getComputedStyle(document.querySelector('.app')).getPropertyValue('--canvas')

// 检查背景色
getComputedStyle(document.querySelector('.backdrop')).backgroundColor

// 检查伪元素
getComputedStyle(document.querySelector('.backdrop'), '::before').background
```

### 对比原版

1. 打开两个浏览器标签
   - 标签1：原版 `index.html`
